# knituuid

Knit HTML/Markdown uuid fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/knituuid/

## Install / run

```bash
git clone https://github.com/theworker02/knituuid.git
cd knituuid
node src/cli.js
node --test
```
